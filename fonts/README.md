# Fonts

Self-hosted (latin subset, variable) so the page and the share card render the same everywhere, X's in-app browser included.

- `anybody.woff2` — Anybody (wdth 50–150, wght 100–900), display and numbers. © 2020 The Anybody Project Authors.
- `jetbrains-mono.woff2` — JetBrains Mono (wght 100–800), everything else. © 2020 The JetBrains Mono Project Authors.

Both under the SIL Open Font License 1.1 (`OFL.txt`). Files from Fontsource (`@fontsource-variable/*` 5.3.0).
